# SoalPintar SD

**SoalPintar SD** adalah proyek untuk membangun platform pembuatan dan bank soal latihan cerdas bagi siswa Sekolah Dasar (SD), yang membantu guru dan orang tua membuat, mengelola, dan memberikan latihan soal yang sesuai dengan kurikulum dan tingkat kemampuan setiap anak.

Repositori ini saat ini berada pada tahap **perencanaan produk dan teknis**. Dokumen utama tersedia di folder [`docs/`](./docs):

- [`docs/PRD.md`](./docs/PRD.md) — **Product Requirements Document**: latar belakang, tujuan, target pengguna, lingkup fitur, dan metrik keberhasilan.
- [`docs/TSD.md`](./docs/TSD.md) — **Technical Specification Document**: arsitektur, tumpukan teknologi (tech stack), model data, desain API, dan rencana implementasi.

## Status Proyek

Tahap saat ini: **Perencanaan (Discovery & Design)**. Implementasi kode aplikasi akan dimulai setelah PRD dan TSD ditinjau dan disepakati.

## Struktur Repositori

```
soalpintar-sd/
├── docs/
│   ├── PRD.md   # Dokumen kebutuhan produk
│   └── TSD.md   # Dokumen spesifikasi teknis
├── package.json
└── README.md
```

## Langkah Selanjutnya

1. Tinjau `docs/PRD.md` untuk memastikan lingkup dan prioritas fitur sudah sesuai kebutuhan.
2. Tinjau `docs/TSD.md` untuk memvalidasi pilihan arsitektur dan teknologi.
3. Setelah disepakati, lanjutkan ke tahap scaffolding aplikasi (misalnya Next.js + TypeScript + Tailwind + shadcn/ui) sesuai rencana pada TSD.
